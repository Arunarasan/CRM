# Workflow — From Enquiry to Handover and Service

The main business journey, who does each step, and where in the app.

## The journey at a glance
**Enquiry → Lead → Requirement → Site visit & measurement → Price & quote → Customer agrees → Project → Execution & installation → Payments → Handover → Service & warranty**

| # | Step | Who | Where | What happens |
|---|---|---|---|---|
| 1 | **Enquiry arrives** | Customer | Website form, WhatsApp, call, walk-in | Website enquiries land in **Website → Enquiries**; admin presses *Convert to lead*. Employees and admins can also add leads directly. |
| 2 | **Lead created** | Admin / employee | Leads → Add Lead; employee My Leads → Add | A *Collect Requirement* task is created and admins are notified. |
| 3 | **Collect requirement** | Employee | Tasks → Collect Requirement | Fill categories, products, budget, photos; set GPS site location. Needs ≥10% to complete. |
| 4 | **Site visit & measurement** | Employee / engineer | Task: Site Visit & Measurement | Record rooms and sizes; customer may sign. Photos saved to the lead. |
| 5 | **Price & quote** | Employee / admin | Lead → Sales Journey → Quote Workspace | Category → product lines, colours, discounts, labour and shipping, GST. Generate the quotation. |
| 6 | **Customer agrees** | Customer / salesperson | Quote link `/q/…` or in workspace | Mark customer-approved. |
| 7 | **Create project** | Admin / PM (employees send for approval) | Quote step → Create Project; admin banner → Approve | Project is created with budget = quote total. Lead documents, drawings and media are copied. Material needs are loaded. Two shared tasks are made: Project Execution and Installation. Advance payment (optional) is recorded. |
| 8 | **Assign team** | Admin | Project → Overview → Project Team | Set Project Manager and Assistant Manager. |
| 9 | **Buy materials** | Admin / PM | Project → Resources → Purchase Orders | Create POs per supplier; receipts later add stock tagged to the project. See workflow 03. |
| 10 | **Execute** | Employees, contractors | Employee tasks; Project → Execution (Execution & Installation) | Steps per product (material, manufacture, stitching, delivery) and install checklists; daily logs and chat; employee daily reports. |
| 11 | **Bill & collect** | Admin / finance | Project → Commercial → Billing & Payments | Milestone invoices auto-raise at work % triggers; record payments; approve cash collected by employees. |
| 12 | **Change order (if needed)** | Admin / PM | Project → Commercial → Quotation → Change | Same project is updated in place when the change is approved. |
| 13 | **Handover** | Admin / PM | Project → **Mark Completed** | Handover sheet: photos, *client approved* and *products delivered* ticks, notes. Project becomes Completed with a handover date. |
| 14 | **Service & warranty** | Admin | Project → Service & Warranty | Activate cover (service and product months); log free or paid service works; paid works raise an invoice. |

## Alternative endings
- **Lead lost:** mark as lost with reason; can be reopened.
- **Project cancelled:** Project → Cancel; optional refund of advance; open tasks closed; unpaid invoices cancelled.
- **Employee cannot create projects:** they use *Send for Approval*; rejection reopens the quote as a new revision.

## Where the customer sees it
- Tracking link `/track/…` (progress and journey) and quote link `/q/…`.
- Review QR `/r/…` after good service.

## Quick Q&A
**Q: Why is the project stuck at 99%?** The Installation closing task is not approved.
**Q: A lead has no tasks.** Only the first task exists at creation; the next appears when it is completed.
**Q: Who gets notified at each step?** Admins for new leads, approvals and payments; PM for task events; employees for assignments.

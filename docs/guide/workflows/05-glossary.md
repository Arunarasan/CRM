# Glossary

| Term | Meaning |
|---|---|
| **Admin** | Account type with full desktop access. |
| **Employee** | Account type using the mobile portal. |
| **Lead** | A possible customer enquiry before any project. |
| **Customer** | A person or company on record; segment **Walk-in** or **Project Client**. |
| **Journey** | The three lead steps: Requirement → Measure & Quote → Project. |
| **Collect Requirement** | First lead task: gather needs, photos, location. |
| **Site Visit & Measurement** | Task to visit and measure the site. |
| **BOQ** | Bill of Quantities: the priced list of work and materials. Now part of the Quote Workspace. |
| **Quote Workspace** | One screen for rooms, price lines and quotation on a lead. |
| **Quotation** | Customer-facing price document; DRAFT, APPROVED, CONVERTED, REVISED. |
| **Revision** | A new editable copy of an approved quote. |
| **Change order** | Editing a running project's quote; updates the same project. |
| **Project** | Work started after the customer agreed; has a Project Manager and Assistant Manager. |
| **Project Execution / Installation** | Two shared tasks every project gets; Installation is the closing task. |
| **Handover** | Final step that marks the project Completed. |
| **Service work** | A post-handover job under Service & Warranty, free or paid. |
| **Work package** | A slice of project scope given to a contractor. |
| **PO** | Purchase order to a supplier. |
| **GRN** | Goods receipt note: record of goods received. |
| **QC** | Quality check on received goods. |
| **Counter sale** | A walk-in sale invoice without a project. |
| **Bundle (Order)** | A customer's item needing stitching/making, tracked with a sticker code. |
| **Cash Book** | Register of all money in and out. |
| **Ledger** | Append-only customer account record; corrections are reversals. |
| **Pay run** | The payroll list for a month. |
| **Hourly / Monthly basis** | The two ways of computing a payslip from hours. |
| **Soft enforcement** | A failed attendance check flags the punch but does not block it. |
| **Kiosk** | A shared phone at the office that punches attendance by face. |
| **Review QR** | An employee's personal QR that leads customers to rate and then to Google reviews. |
| **Enquiry** | A website form submission waiting in the Enquiries inbox. |
| **Tracking link** | Private no-login page showing a project's progress. |
| **Smart Assign** | The recommender that ranks employees for a task. |
